# Worker-text bridge fixture integration

The new seven-case inventory is `tools/vulkan-raster-probe/worker-text-fixtures/inventory.json`; its typed projection is the adjacent `fixture_inventory.rs`. The existing original 30 probe, 16 browser bridge and 26 glyph populations stay unchanged. Each case is 160×80, giving 51,200 packed-u32 bytes. Six GPU cases total 307,200 bytes; the one whole-frame fallback totals 51,200 CPU bytes. Combined targets total 358,400 bytes per adapter run, and these categories must remain separately reported.

Use the agreed `WorkerTextFixture`/`ExpectedText`/`ExpectedImage`/`DrawingKind` types directly from the data-only Rust table. Spawn one fresh worker at a time, scripts disabled, generation `3000 + index`, navigate by GET to the exact canonical local `html_file` under the supplied directory and request Render at the frame size. Require no Load snapshot/navigation, no Render navigation, exact generation/title/URL, edit sequence zero and idle task state. Dump every unpruned snapshot through the existing complete EWB1 format before checking assumptions. Expected x/y coordinates are intentionally absent.

Require every Text in exact content/order/style/size/RGBA sequence. Validate clip and fixed membership by replaying scopes: translate clip rectangles by active offsets; PushFixed resets to caller clip and viewport offset; Pop restores the enclosing clip/offset. `clipped` means an effective restrictive clip relative to the full caller/viewport. Reject mismatched/unbalanced scopes. Drawing-order projection removes scope instructions and only transparent/empty radius-zero Rects; it never removes Text/Image/Line or unsupported rounded/opacity paint from the actual input. For the image case require one key `two-pixels.png`, exact 2×1 decoded RGBA, two original references and the specified interleaving.

Pixel correctness is same-snapshot original-Canvas differential comparison, with preserved full packed `0x00RRGGBB` targets and exhaustion refusal. These are not independent font goldens or cross-engine conformance outputs. Successful fonts-aware admission must exactly match the prescribed GPU route; the rounded case must refuse the whole list as `unsupported-rounded-rectangle`, retaining the actual original rejection index as an observation. Do not execute a partial plan on fallback.

After all seven sequential captures and CPU/font preparation, drop workers, inputs and Fonts before any Vulkan access; use the unchanged subreaper supervisor's mandatory GPU_READY grant and emit an explicit capture-complete phase. Follow with all 1–16 enumerated adapters and fail closed on the first process, protocol, identity, cleanup or comparison failure. No engine embedding or production window path is needed.

Source assumptions reviewed before any worker output: current layout emits separate word/space Text commands; inline style flags/size/RGBA are copied directly; body propagation emits one canvas background; positioned auto-z groups preserve DOM paint order; a fixed descendant forms its own root stacking context and escapes ancestor overflow; decoration emits Line after Text. The scroll document sets body position static specifically to give SCROLL→FIXED→AFTER root paint order. Real captures must confirm these assumptions rather than update the frozen inventory.
