# Native-window inputs

These two local documents are fixed before any native-window observation. Both
request a real worker-loaded page with short text, one decoded image, a fixed
text element and tall content that requires a scrollbar at the normal 1180×880
window. Scripting is disabled. The second adds group opacity and must use the
complete existing CPU route.

The admitted verification run compares the actual acquired Vulkan texture to
the original Canvas reference for that same completed scene. This is a
differential reference, not an independent font or page-layout pixel oracle.
A matching serial/generation must join the loaded-scene and acquired-verification
records; startup chrome alone does not establish page rendering. A separate
normal run requires reference=false. The opacity run records admission fallback
and does not claim a native-shader pixel comparison. Surface pixels are observed
before the desktop compositor; no screenshot or performance claim follows.

`two-pixels.png` is copied unchanged from the earlier frozen worker-text fixture.
The manifest binds exact input bytes. No browser, Canvas, planner or GPU was
executed while authoring these inputs.
